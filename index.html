2. 물질의 연소

파란 카드 = 교과서 · 읽고 지켜보기초록 카드 = 실험관찰 · 내가 직접 해 보기

교과서는 결과를 예상하고 3D 실험을 지켜본 뒤 날개를 들어 정답을 확인해요. 실험관찰은 직접 끌고 눌러 실험하고, 관찰 기록지를 체크하거나 가림막을 열어 정리해요.

1서로 다른 물질을 섞으면 어떻게 될까?

특별 활동더 해 보기 모둠 순환 실험 · 한 사람씩 해 보기 일곱 가지 물질 섞기 실험실 식초·석회수·우유·생석회·아이오딘 용액 등을 섞어 보며 색 변화, 기포, 흐려짐·덩어리, 온도 변화를 관찰하고 설탕물과 비교해요. 실험실 들어가기 → 교과서읽고 지켜보기 과학 38~39쪽 밀가루와 탄산수소 나트륨을 식초에 넣으면 풍선을 세우면 한쪽은 이산화 탄소로 부풀고, 다른 쪽은 다시 처져요. 펼쳐 보기 → 실험관찰내가 직접 해 보기 실험관찰 22~23쪽 · 직접 해 보기 가루 넣기부터 풍선 세우기까지 깔때기로 가루를 넣고, 식초를 기준선까지 붓고, 두 풍선을 동시에 세워요. 실험하러 가기 →

2물질이 탈 때 어떤 현상이 나타날까?

교과서읽고 지켜보기 과학 40~41쪽 양초와 알코올이 탈 때 나오는 빛과 열 두 불꽃을 비교하고, 빛과 열이 퍼져 나가는 흐름을 눈으로 봐요. 펼쳐 보기 → 실험관찰내가 직접 해 보기 실험관찰 24~25쪽 · 직접 해 보기 안전 점검부터 불 끄기까지 양초와 알코올램프에 불을 붙이고, 불꽃·따뜻함·시간 변화를 관찰해요. 실험하러 가기 →

3물질이 타려면 무엇이 필요할까?

교과서읽고 지켜보기 과학 42~44쪽 산소의 영향과 온도의 영향 아크릴 통 속 두 촛불을 비교하고, 철판 위 성냥 머리와 나무 중 무엇에 먼저 불이 붙는지 지켜봐요. 펼쳐 보기 → 실험관찰내가 직접 해 보기 실험관찰 26~27쪽 · 직접 해 보기 비커 준비부터 철판 가열까지 과산화 수소수를 붓고, 두 통을 동시에 덮고, 성냥 조각을 같은 거리에 놓아 가열해요. 실험하러 가기 → 특별 활동더 해 보기 핵심 정리 · 과학 44쪽 연소의 조건 모으기 떠다니는 것 중 탈 물질, 산소, 발화점 이상의 온도를 골라 모으면 가운데에 불이 붙고 「연소의 조건」 글자가 떠올라요. 하나씩 빼 보며 불이 꺼지는 까닭을 확인해요. 조건 모으러 가기 →

4연소 후의 변화가 궁금해!

교과서읽고 지켜보기 과학 46~47쪽 연소 후 생성되는 물과 이산화 탄소 푸른색 염화 코발트 종이가 붉게 변하고 석회수가 뿌옇게 흐려지는 것을, 생성된 물질 알갱이와 함께 지켜봐요. 펼쳐 보기 → 실험관찰내가 직접 해 보기 실험관찰 28~29쪽 · 직접 해 보기 종이 붙이기부터 석회수 흔들기까지 핀셋으로 종이를 붙이고, 촛불을 덮고, 석회수 병의 뚜껑을 닫아 직접 흔들어 변화를 관찰해요. 실험하러 가기 →
