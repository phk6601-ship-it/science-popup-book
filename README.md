## GitHub Pages로 공개하기
1. 이 폴더의 파일을 저장소 맨 위(루트)에 그대로 올립니다.
2. 저장소 **Settings → Pages**에서 Branch를 `main` / `/(root)`로 고르고 저장합니다.
3. 잠시 뒤 `https://<아이디>.github.io/<저장소이름>/` 주소로 목차가 열립니다.

3D 도구(three.js)는 cdn.jsdelivr.net에서, 글꼴은 Google Fonts에서 불러옵니다.
